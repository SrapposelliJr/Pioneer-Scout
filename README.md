# Pioneer Scout

An interactive baseball scouting platform built in **R** and **Shiny** for evaluating players in the Pioneer Baseball League.

Pioneer Scout combines automated data collection, machine learning, player evaluation, and interactive dashboards into a single app designed to support baseball scouting and player acquisition.

---

## Dashboard Features

- Interactive hitter scouting reports
- Interactive pitcher scouting reports
- Team pages
- Player headshots
- Team logos
- Scout Grades
- MLB Signing Probability Model
- Prospect rankings
- Advanced hitting metrics
- Advanced pitching metrics
- Analytics dashboard


## Technologies
